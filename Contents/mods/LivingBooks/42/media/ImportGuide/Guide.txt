Before you begin:
- 42/media/scripts/LivingBooksItems.txt RENAME IT to "LivingBooksYOURBOOK.txt", open it and modify the item name (leave the module and properties untouched). Watch out for syntax errors. If you want to make a pack of books duplicate the item block inside the file if you want to add more books.
- Convert your book to JSON (for example: https://pdfjar.com/pdf-to-json) using the structured format without metadata. [Free, no account required].
- Place the generated JSON file into: 42/media/books
- Modify the file called "books.txt" inside the same folder: 42/media/books/books.txt
- Add the full filename of your JSON book on a new line (ExampleBook.json).
- Fill in the "itemFullType" field using the item name you created in "media/scripts/LivingBooksItems.txt" (Module.ItemName).
- Edit/fix the JSON so it matches the following format (add the author if it isn't already included).

JSON Structure: The comments (-- text --) are only there to guide you. Delete them if you copy this text block

{
  "filename": "Book Title",                        -- REQUIRED --
  "itemFullType": "Module.ItemName",               -- REQUIRED! Must match the item defined in "42/media/scripts/LivingBooksItems.txt" (this file must be included in your addon) Leave this field blank if you are collaborating by submitting your own book through our form. -- 
  "author": "Book Author",                         -- REQUIRED --
  "pageCount": Number,                             -- Optional --
  "pages": [
    {
      "pageNumber": 1,                             -- Optional --
      "headings": [                                -- Optional --
        {
          "text": "Chapter Title",                 -- Required if Heading, Large font, intended for chapter headings. --
          "level": 2                               -- Required if Heading, Always put 2
        }
      ],
      "paragraphs": [
        "Book text"
      ]
    },                                             --> Do not leave empty spaces, and always separate pages or paragraphs with commas.
    {
      "pageNumber": 2,
      "headings": [],
      "paragraphs": [                              --> Next page, with or without headings.
        "Book text"
      ]
    }
}
--> The JSON should end exactly like this.

Final tips:
- To insert a line break inside a paragraph, use \n (example: Word\nWord). However, avoid using it in the title or author fields, as it may cause visual issues. Use it only when needed.
- If you add more than one paragraph or page, always separate each element with a comma, and never leave empty entries.
- The Enemy Lua and ZedScript extensions for Visual Studio Code (recommended on the official wiki) can help you detect syntax and typing errors.
- Don't worry about book length. Since books only contain text, LivingBooks can handle books with over 2,000 pages with virtually no performance impact.

Remember:
- Each content pack contains exactly ONE book. If you want to add multiple books, create several small content-pack mods, or make a dedicated multi-book pack.
- "itemFullType" is the ONLY thing linking this JSON to an in-game item. LivingBooks scans every activated mod for media/books/book.json files when the game starts and matches them with the inventory item whose FullType is an exact match.
